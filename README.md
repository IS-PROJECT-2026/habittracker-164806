# Habit Tracker

A minimal, high-contrast habit tracking app — add habits, mark them done each day, and watch your streak grow. Built as a static site with no backend, using localStorage for persistence.

**Live demo:** https://is-project-2026.github.io/habittracker-164806/

## Features

- Add and delete habits
- Mark a habit complete for the current day
- Automatic streak calculation (consecutive days completed)
- 7-day weekly progress grid per habit
- Dark mode toggle with saved preference
- Fully responsive layout
- All data persisted locally in the browser (no account or backend required)

## Technologies Used

- HTML5
- CSS3 (custom properties, flexbox, media queries)
- Vanilla JavaScript (no frameworks)
- Browser localStorage for persistence
- GitHub Pages for deployment
